## 六、⚠️ 关键约定（改代码前必看，否则会踩坑）

1. **vnpy 读配置在 `~/.vntrader/vt_setting.json`**，不是项目里的 `vt_setting.json`！改数据库连接必须改家目录那个。
2. **vnpy_postgresql 驱动被打过补丁**：表名改为 `quant_data`/`quant_data_sync`，且 `create_tables` 只建两张表。
   **如果重装/升级该包，补丁丢失** → 重跑 `deploy/patch_vnpy_postgresql.py`（幂等）。
3. **本地 python 必须用 `.venv/bin/python`**，不要用系统 python。
4. **代码风格**：改完跑 `.venv/bin/ruff check .`。
5. **不要动 `vnpy/` 框架核心**。
6. **策略写法**：继承 `CtaTemplate`，类属性声明 `parameters`(可调)/`variables`(状态)，逻辑写在 `on_bar`，下单只用 `self.buy/sell/short/cover`。
7. **策略文件放 `strategies/`**，命名 `daily_YYYYMMDD_<name>.py`，`registry.py` 自动发现，无需手动注册。
8. **git 仓库公开**（github.com/xucongyong/vnpy_uv_macos），注意别提交密码；建议用户设私有。
